# Check a modeled retrofit choice against another weather case

A simulation can rank a retrofit first under one weather-year case and differently under another. This study will compare nominal, worst-case and minimax-regret choices using published ComStock results, keeping simulated savings separate from field evidence.

**Current state: protocol before annual-data collection.** No stable ranking, investment return or realized saving is established. The [protocol](PROTOCOL.md) fixes a bounded Vermont model cohort, two source weather cases, four existing upgrade scenarios, a no-action baseline and independent checks. Operating-duration groups are diagnostics, not a controlled occupancy experiment. Formal-publication projects remain private.
